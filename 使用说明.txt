使用说明 · 校园志愿时长汇总助手
================================================================

一、先看这个（不需要装任何东西）
----------------------------------------------------------------
双击 slide.html，用浏览器打开即可播放汇报幻灯片（15 页）。
    ← → 或 空格   翻页
    P             打印 / 另存为 PDF
无需联网、无需安装 Python、无需任何配置。
建议用 Chrome / Edge 打开。

二、如果想运行程序本体
----------------------------------------------------------------
环境要求：Python 3.10 及以上（推荐 3.11 / 3.13）

1) 进入项目目录，安装依赖
       pip install -r requirements.txt

2) 配置 API Key（必须，否则页面会提示缺少 Key）
   把 .env.example 复制一份，改名成 .env
   用记事本打开 .env，把 DASHSCOPE_API_KEY 的值换成自己的
   阿里云百炼控制台可以免费申请：
       https://bailian.console.aliyun.com/

       DASHSCOPE_API_KEY=sk-你的密钥
       DASHSCOPE_MODEL=qwen-plus

3) 启动
       streamlit run app.py
   浏览器自动打开 http://localhost:8501

三、怎么用（四步走完整个流程）
----------------------------------------------------------------
第一步：绑定个人账号（先做这个）
    左侧栏最上方「👤 个人账号」：
      · 直接下拉选演示账号：张三 / 李四 / 王五 / 赵六 → 点「绑定 / 切换」
      · 或选「➕ 新建我的账号」，填自己的姓名、学号、学院 → 点「绑定这个账号」
    绑定后页面上方会出现账号条，显示：
        当前账号 / 学号 / 我的记录数 / 我的总时长 / 校内时长 / 校外时长
    再上面是四张只属于你自己的卡片，从左到右依次是：
        ⏱️ 累计志愿总时长 —— 第一位、最宽，深色大字卡最醒目，卡内细条显示校内/校外占比
        🏫 校内志愿时长
        🌆 校外志愿时长
        📋 我的志愿记录总数 —— ★ 在最后一位，点这张卡片可展开你的每一条志愿记录
        点「🔼 收起明细」可把明细收回去；明细面板可切「全部 / 校内 / 校外」
    姓名和学号只需在这里填一次，之后录入志愿记录不用再填。

    ★ 切换账号时，志愿记录会一起切换：
        · 左侧数据表变成新账号的记录（想看全部人，打开「显示全部成员的记录」）
        · 四张卡片换成新账号的记录数、总时长与校内/校外分项，明细也一起换人
        · 上一个账号的查询结果、统计表、柱状图、Excel 下载会被清空
        · 对话也会清空，避免新旧账号的数据混在一起
        · 导出文件名会带上账号名，例如 志愿时长汇总_李四_20261027_1530.xlsx

第二步：录入自己的志愿活动（只填名称和时长）
    左侧栏「➕ 录入我的志愿记录」：
        志愿活动名称  例：社区垃圾分类督导
        服务日期      默认今天，可改
        志愿时长(小时) 默认 3，可调（0.5 小时为一档）
        服务地点      可选
        类型          校内 / 校外，留空按活动名自动判断（图书馆/迎新/运动会…算校内）
    提交后记录直接写到你绑定的账号名下。
    也可以在对话框说一句：
        帮我记一笔：今天参加社区垃圾分类督导 3.5 小时
    模型会自动调用录入工具，同样不需要你报姓名学号。

第三步：看学校、看活动、去报名
    程序启动即默认绑定「上海杉达学院（金海校区）」，
    左侧栏「学校绑定」按 ① 省份 → ② 城市 → ③ 搜索校名 → ④ 选择学校
    四步操作，内置全国 1308 所本科高校（含港澳台），绑定后活动地区
    自动切到学校所在省市。
    页面上方学校状态条显示：校内活动数 / 当前活动地区 / 覆盖区数 / 最近活动距离。
    页面最下方「活动中心」：
      · 顶部三个下拉：省份 → 城市 → 区县（全国 34 省 / 368 市 / 3078 区县）
      · 「活动范围」单选：全部 / 校内 / 校外
      · 关键字输入框，可搜标题、主办、标签
      · 「↩️ 回到本校」一键回到绑定学校所在地区
      · 下面一条面包屑实时显示：范围 · 地区 · 关键字 · 共 N 个（校内 X / 校外 Y）
      · 校内活动自动刷新，报名人数会变，有新活动会推入并标记 NEW
      · 校外活动在所选区县生成；与校区同城时按距离由近到远，
        跨市时改按日期排列（跨市距离没有参考意义）
    每张卡片下方点开「📄 活动详情与报名」，可以看到：
        活动介绍 / 招募对象 / 集合信息 / 联系人 / 注意事项
    详情底部有「🔗 前往官方平台报名」按钮，直接跳转报名页面。

第四步：对话查询与导出
    在对话框依次输入：
        1. 帮我查询我 2026-10-01 到 2026-10-31 的志愿记录
        2. 统计 2026-09-01 到 2026-10-31 每个人的累计志愿总时长
        3. 把上面的结果导出成 Excel
    第 1 句默认只查「我」的记录；第 2 句说了「每个人」，
    模型会自动改成全员口径（工具参数 scope 从 me 变 all）。
    也可以直接问活动：
        4. 这周学校有哪些志愿活动可以报名
        5. 上海有哪些科普类的志愿活动
        6. 成都武侯区有什么志愿活动
        7. 帮我在鼓楼区找找志愿活动（只说区县也会自动反查省市）
        8. 我校内和校外的志愿时长分别是多少，总共多少小时

每说一句，右侧「工具调用日志」会增加一条记录，
显示模型调用了哪个工具、传了什么参数、返回了什么结果。
统计完成后柱状图会自动出现，导出完成后侧栏会出现下载按钮。

四、文件说明
----------------------------------------------------------------
    app.py                    主程序：Agent 循环 + 6 个工具 + 账号/学校绑定 + 活动中心
    geo.py                    地区与高校数据层（省市区县查询、院校检索、距离计算）
    regions.json              34 省 / 368 市 / 3078 区县（离线索引）
    universities.json         1308 所本科高校（校名、省市、校区、经纬度）
    tools/build_geo_data.py   从开源数据集重新生成上面两个 json（可选）
    requirements.txt          依赖清单（6 个包）
    .env.example              环境变量模板（不含真实密钥）
    .gitignore                版本管理排除规则
    .streamlit/config.toml    页面主题配置
    slide.html                汇报幻灯片（双击打开）
    slide.md                  幻灯片 Markdown 源文件
    README.md                 项目文档

五、注意事项
----------------------------------------------------------------
1. 本压缩包不含 API Key，需要你自己申请并填入 .env
2. 志愿记录为模拟数据（4 人、12 条记录、合计 46.0 小时，其中校内 27.5 / 校外 18.5），
   重启程序会恢复初始状态；省市区县与高校名单是公开开源数据（真实），
   活动条目是按地区模板生成的演示内容
3. 界面上的录入记录、绑定账号、绑定学校只保存在当前会话中，不会写进文件
4. 个人账号是本地会话内绑定（无密码、不校验学号真伪），只用于自动带入姓名学号
5. 如果出现「接口限流」，等半分钟再试，程序已内置自动重试
6. 侧栏有「测试模型连接」按钮，可以先点它确认接口是否正常
7. 活动内容是按模板生成的演示数据，不是主办方实时接口；
   报名按钮跳转到官方平台（上海志愿者网等），具体活动需在平台内检索
8. 活动中心的「实时更新」是本地定时器模拟（每 25 秒），不是真实抢票式刷新
9. 校外距离是直线距离估算，实际通勤会更远；跨市不计算距离；区县重名时按行政区划数据首个匹配
