使用说明 · 校园志愿时长汇总助手
================================================================

一、先看这个（不需要装任何东西）
----------------------------------------------------------------
双击 slide.html，用浏览器打开即可播放汇报幻灯片（12 页）。
    ← → 或 空格   翻页
    P             打印 / 另存为 PDF
无需联网、无需安装 Python、无需任何配置。
建议用 Chrome / Edge 打开。

二、如果想运行程序本体
----------------------------------------------------------------
环境要求：Python 3.10 及以上（推荐 3.11 / 3.13）

1) 进入项目目录，安装依赖
       pip install -r requirements.txt

2) 配置 API Key（必须，否则页面会提示缺少 Key）
   把 .env.example 复制一份，改名成 .env
   用记事本打开 .env，把 DASHSCOPE_API_KEY 的值换成自己的
   阿里云百炼控制台可以免费申请：
       https://bailian.console.aliyun.com/

       DASHSCOPE_API_KEY=sk-你的密钥
       DASHSCOPE_MODEL=qwen-plus

3) 启动
       streamlit run app.py
   浏览器自动打开 http://localhost:8501

三、怎么用（三句话走完整个流程）
----------------------------------------------------------------
第一步：绑定学校
    左侧栏顶部「绑定学校」下拉选择学校，点「绑定」。
    绑定后页面上方会出现一条学校状态条，显示
    校内活动数 / 校外活动数 / 最近活动距离。

第二步：看活动
    页面最下方「活动中心」有两个页签：
      · 校内活动 —— 自动刷新，报名人数会变，有新活动会推入并标记 NEW
      · 校外活动 —— 按距离从近到远排序，可拖动滑杆调整推送半径（1~20 km）
    打开「自动刷新」开关即可持续更新，也可以点「刷新活动」手动刷新。

第三步：对话查询
    在对话框依次输入：
        1. 帮我查询 2026-10-01 到 2026-10-31 的志愿记录
        2. 统计 2026-09-01 到 2026-10-31 每个人的累计志愿总时长
        3. 把上面的结果导出成 Excel
    也可以直接问活动：
        4. 这周学校有哪些志愿活动可以报名
        5. 学校附近 3 公里内有没有环保类的活动

每说一句，右侧「工具调用日志」会增加一条记录，
显示模型调用了哪个工具、传了什么参数、返回了什么结果。
统计完成后柱状图会自动出现，导出完成后侧栏会出现下载按钮。

四、文件说明
----------------------------------------------------------------
    app.py                    主程序：Agent 循环 + 4 个工具 + 活动中心 + 页面
    requirements.txt          依赖清单（6 个包）
    .env.example              环境变量模板（不含真实密钥）
    .gitignore                版本管理排除规则
    .streamlit/config.toml    页面主题配置
    slide.html                汇报幻灯片（双击打开）
    slide.md                  幻灯片 Markdown 源文件
    README.md                 项目文档

五、注意事项
----------------------------------------------------------------
1. 本压缩包不含 API Key，需要你自己申请并填入 .env
2. 数据为模拟数据（4 人、10 条记录；4 所学校、8 个活动），重启程序会恢复初始状态
3. 界面上新增的记录、绑定的学校只保存在当前会话中，不会写进文件
4. 如果出现「接口限流」，等半分钟再试，程序已内置自动重试
5. 侧栏有「测试模型连接」按钮，可以先点它确认接口是否正常
6. 未绑定学校时问活动，助手会提示你先绑定，不会编造活动数据
7. 活动中心的「实时更新」是本地定时器模拟（每 25 秒），不是真实校方接口
