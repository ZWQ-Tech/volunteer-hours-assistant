03 · 架构

五层结构：模型决策，代码执行

模型不接触原始数据，只传参数；所有计算与文件生成在本地完成
A交互层 Streamlit 页面：对话区 · 工具日志 · 结果表格 · 柱状图 · 下载按钮 · 活动中心
用户输入文本，提交到 st.chat_input
B会话层 维护 messages 与 st.session_state，装配 tools 协议，驱动调用循环（上限 6 轮）
chat.completions.create(model, messages, tools)
C模型层 通义千问 qwen-plus（DashScope OpenAI 兼容接口）：意图理解 · 工具选择 · 参数生成
返回 tool_calls（工具名 + JSON 参数）
D工具层 五个本地函数：查询 / 统计 / 导出 / 活动查询 / 记录录入，执行后以 JSON 回填，形成下一轮上下文
pandas 筛选与分组 · openpyxl 写出文件 · Haversine 算距离
E数据层 内存数据表 st.session_state.volunteer_df（10 条记录）+ 学校与活动池 + 最近结果缓存

05 · 工具设计

五个工具的入参、返回与取舍

工具均为项目内自行实现，参数结构直接决定模型能否稳定调用
Q
query_volunteer_data
start_date 必填
end_date 必填
project_name 可选
{ status, count, message, records[] }
status: success / empty / error
Σ
calc_total_hours
records 可选
省略时取最近一次查询结果
{ status, summary[{姓名, 总时长, 参与次数}], 总计 }
↓
export_volunteer_excel
summary 可选
省略时取最近一次统计结果
{ status, filename, message }
📍
query_open_activities
scope 可选 · 校内/校外
district 可选 · 上海各区
keyword 可选
{ status, school, on_campus[], off_campus[] }
校外按距离升序
＋
add_volunteer_record
project_name 必填
hours 必填
date / place 可选
{ status, record, personal_total }
姓名学号取自绑定账号
# 工具定义（节选） "name": "query_open_activities", "parameters": { "properties": { "scope": {"enum": ["all","on_campus","off_campus"]}, "district": {"type": "string", # 浦东新区 / 徐汇区… "description": "上海某个区，不传=全市"}, }, "required": [] }
取舍一 · 可选参数
用户不必说全条件，模型可采用默认行为
取舍二 · 数据不回传
统计与导出省略数组参数，避免长 JSON 被截断导致 400
取舍三 · 状态三值
success / empty / error 让模型分别给出结果、提示或修正建议
取舍四 · 距离不由模型算
距离排序交给 Haversine 公式，区域由参数限定，防止模型编造
取舍五 · 身份不进参数
姓名学号取自绑定账号，模型无需询问也无权填写，避免张冠李戴

10 · 合规说明

数据来源、隐私与使用边界

演示效果让位于合规：不使用真实学生信息，不在交付物中出现密钥
数据来源
全部为课程自建模拟数据，姓名学号为虚构占位；仅存在于本机内存，不写入第三方服务
隐私与密钥
密钥存 .env 并由 gitignore 排除；代码、仓库、幻灯片中均不含真实 Key
使用边界
课程演示原型，不作正式认定依据；真实场景需补登录鉴权、数据脱敏、操作留痕
学术诚信
工具调用由模型真实发起，未用关键词判断伪造能力；数据由工具真实计算，无预埋答案
位置信息：仅使用学校公开的校区经纬度估算活动直线距离，不采集、不存储用户实时定位；活动数据为课程自建模拟池。
统计结果最终以学校志愿管理系统的原始记录为准；本工具用于减轻重复劳动，不替代认定流程。
